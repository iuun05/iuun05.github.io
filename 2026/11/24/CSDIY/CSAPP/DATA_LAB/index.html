CS:APP Data Lab 笔记

Data Lab 考察补码整数的位级表示与 IEEE 754 单精度浮点数编码。整数部分禁用分支、循环、大常数（只能用 0x00 ~ 0xFF）和部分运算符；浮点数部分允许使用分支与常规算术逻辑。

整数位运算与补码（10 题）

bitXor(x, y) —— 仅用 ~ 和 & 实现异或

  • 核心思路： 异或等价于“不同时为 0 且不同时为 1”。利用德摩根定律将 | 转换为 & 和 ~：x⊕y=(x∨y)∧¬(x∧y)=¬(¬x∧¬y)∧¬(x∧y)x \oplus y = (x \lor y) \land \neg(x \land y) = \neg(\neg x \land \neg y) \land \neg(x \land y)x⊕y=(x∨y)∧¬(x∧y)=¬(¬x∧¬y)∧¬(x∧y)。

tmin() —— 返回 32 位补码最小值

  • 核心思路： 32 位补码最小值为 −231-2^{31}−231（0x80000000），将 1 左移 31 位即可。

isTmax(x) —— 判断是否为补码最大值 0x7FFFFFFF

  • 核心思路： Tmax（0x7FFFFFFF）加 1 会溢出变成 Tmin（0x80000000），此时满足 x == ~(x + 1)。但 -1（0xFFFFFFFF）加 1 变成 0 也满足 x == ~(x + 1)，因此必须用 !!(x + 1) 排除 x == -1。

allOddBits(x) —— 判断所有奇数位是否全为 1

  • 核心思路： 常数不能超过 0xFF，通过移位和按位或构造掩码 0xAAAAAAAA（二进制 1010...1010）。用 mask & x 提取奇数位，再与 mask 异或判断是否完全一致。

negate(x) —— 求相反数 -x

  • 核心思路： 补码定义，按位取反加 1。

isAsciiDigit(x) —— 判断 0x30 <= x <= 0x39

  • 核心思路： 转化为判断 0x39 - x >= 0 且 x - 0x30 >= 0。做减法后算术右移 31 位提取符号位，两个差值的符号位均必须为 0（注意：x 为极端大/小值时虽然可能溢出，但高位会直接导致其中一个差值为负，逻辑依然成立）。

conditional(x, y, z) —— 实现三目运算符 x ? y : z

  • 核心思路： 利用 !!x 将 x 归一化为 0 或 1。构造全 0 或全 1 的掩码：~1 + 1 = 0xFFFFFFFF，~0 + 1 = 0x00000000，分别与 y 和 z 相与后拼接。

isLessOrEqual(x, y) —— 判断 x <= y

  • 核心思路： 直接计算 y - x 在异号时会溢出，需按符号位分情况讨论：
  1. x 与 y 异号（oppositeSign == 1）：仅当 x 为负（xSign == 1）时满足 x <= y。
  2. x 与 y 同号（oppositeSign == 0）：y - x 不会溢出，判断差值符号位 diff == 0 即可。

logicalNeg(x) —— 不用 ! 实现逻辑非 !x

  • 核心思路： 0 是唯一一个“本身与相反数（~x + 1）的符号位都为 0”的整数；任何非零数（包括 Tmin）与 -x 按位或后，最高位必为 1。算术右移 31 位后，非零数得 -1，0 得 0。

howManyBits(x) —— 补码表示 x 所需的最少位数

  • 核心思路： 负数按位取反（~x）所需的位数与原负数完全相同，因此先通过符号位掩码统一转为非负数 absX；随后用二分查找定位最高位 1 的下标（依次试探高 16、8、4、2、1 位），最后加上最高位自身和 1 位符号位。

IEEE 754 单精度浮点数（3 题）

单精度浮点数布局：1 位符号位 s（bit 31）+ 8 位阶码 e（bits 30~23，偏置值 Bias = 127）+ 23 位尾数 f（bits 22~0）。

floatScale2(uf) —— 计算 2.0 * f

  • 核心思路： 拆出 s、e、f 分三类处理：
  1. e == 0xFF（NaN 或 ±∞\pm\infty±∞）：直接原样返回 uf。
  2. e == 0（非规格化数）：尾数直接左移 1 位（若最高位溢出到第 23 位，恰好无缝进位变成最小规格化数）。
  3. 规格化数：阶码 e + 1；若加完后 e == 0xFF，说明上溢，返回对应符号的无穷大。

floatFloat2Int(uf) —— 浮点数强转 (int) f

  • 核心思路： 计算真实指数 E=e−127E = e - 127E=e−127：
  1. E<0E < 0E<0：数值绝对值小于 1，向零截断返回 0。
  2. E≥31E \ge 31E≥31：超出 32 位 int 表示范围（含 NaN 与无穷大），按题意返回 0x80000000u。
  3. 有效区间 0≤E≤300 \le E \le 300≤E≤30：补上隐含前导 1 构成 M = frac | (1 << 23)，根据 EEE 与 23 的差值左移或右移对齐，最后恢复符号。

floatPower2(x) —— 计算 2.0x2.0^x2.0x 的单精度位表示

  • 核心思路： 按指数 xxx 落入的 IEEE 754 区间分段构造：
  • x>127x > 127x>127：上溢，返回 +INF（0x7F800000）。
  • −126≤x≤127-126 \le x \le 127−126≤x≤127：规格化数区间，阶码为 x+127x + 127x+127，尾数全 0。
  • −149≤x≤−127-149 \le x \le -127−149≤x≤−127：非规格化数区间，阶码为 0，尾数部分第 x+149x + 149x+149 位置 1（最小表示 2−126×2−23=2−1492^{-126} \times 2^{-23} = 2^{-149}2−126×2−23=2−149）。
  • x<−149x < -149x<−149：下溢，返回 0。
